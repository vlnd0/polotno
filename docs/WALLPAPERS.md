# Built-in Polotno wallpapers

These files are original procedural artwork generated by `scripts/generate-wallpapers.py`, licensed under the project's MIT license. They contain no third-party footage or private media.

The manifest records the choices and content-hashed media filenames. All videos are seamless 8-second H.264 SDR 1280×720/30 loops. JPEG frames are used as lightweight catalog posters and independently selectable static artwork.

To regenerate with FFmpeg installed:

```sh
python3 scripts/generate-wallpapers.py
```
