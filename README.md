# Полотно · Polotno

Название продукта — **Полотно**, международное написание и имя репозитория — **Polotno** (`polotno`).

Автономная галерея для Android TV проекторов: картины и видео в отдельных областях стены, настройка из браузера телефона или компьютера и запуск с пульта или как заставки.

## Статус

Подготовлен план реализации. Приложение пока не реализовано; APK отсутствует.

Первое целевое устройство — XGIMI MoGo 3 Pro G0035, Android 14, 1920×1080.

## Возможности первой версии

- Произвольное количество областей с подгонкой четырёх углов, порядком наложения и отдельными плейлистами.
- Максимум два одновременно воспроизводимых видео; количество картин не привязано к этому ограничению.
- Настройка по QR-коду из браузера в домашней Wi-Fi сети.
- Локальное хранение сцен и медиа; сохранённая галерея работает без телефона, компьютера и интернета.
- Каталог открытых музейных коллекций и Wikimedia Commons, импорт собственных файлов и выбранных изображений.
- Управление пультом и системная Android-заставка.

## Стек

Kotlin и Media3 для Android, OpenGL ES для рендера, Rust и Axum для встроенного сервера, TypeScript и React для браузерного редактора. Отдельный сервер не требуется.
